# ✦ BlissOS Antigravity for Termux ✦
> **Pocket AI Coding Agent Engine for Android (Termux + Debian glibc)**  
> *Crafted by BlissOw (github.com/BlissOw)*

---

## ⚡ Описание
Официальный **Google Antigravity CLI** создан под классический Linux с библиотекой `glibc` (ARM64).  
В чистом Termux на Android работает легковесная `bionic libc`, из-за чего запуск тяжелых бинарников упирается в ограничения памяти (TCMalloc 39-bit) и несовместимость библиотек.

**BlissOS Antigravity Edition** решает эту проблему элегантно:
* Использует изолированный контейнер **Debian ARM64** через официальный `proot-distro`.
* Нативный `glibc` 2.36+, поддержка UTF-8, Python 3, Git, Node.js.
* **Тонкая оптимизация RAM:** ограничение выделения памяти `MALLOC_ARENA_MAX=2` и `NODE_OPTIONS` специально под устройства с 3–4 ГБ оперативной памяти (Snapdragon 625 / Redmi 5 Plus).
* **Мгновенный запуск в 1 команду:** из любого места в Termux достаточно ввести `bliss` или `agy`!
* **Монтирование памяти:** внутренняя память телефона `/sdcard` автоматически примонтирована внутрь окружения, так что агент имеет прямой доступ к файлам смартфона.

---

## 🚀 Установка в 1 клик

Открой **Termux** на телефоне и вставь команду:

```bash
curl -sSL https://raw.githubusercontent.com/BlissOw/BlissOS/main/termux_antigravity/install.sh | bash
```

---

## 🎮 Использование

После установки в Termux появляются две короткие команды:

```bash
bliss
```
или
```bash
agy
```

Ты сразу попадаешь в изолированную, быструю среду с полным набором инструментов разработчика и ИИ-агентом!

---

## 📁 Структура
* `install.sh` — автоматический установщик зависимостей Termux, Debian-контейнера и шорткатов.
* `/usr/local/bin/agy` — оптимизированный лаунчер окружения с правильными переменными среды.
* Доступ к хранилищу: `/sdcard` (можно редактировать скрипты, проекты и ботов прямо на телефоне).
